# MINA CHRONICLE 〜光と音を永遠に〜

**E16星系を舞台にした、ファイナルファンタジー風の本格長編RPG（PWA完全対応・ビルド不要の純静的サイト）**

EDU統合版設定（M104銀河・E16星系年代記）の正史（カノン）をベースに、
AURALIS二代目・**ミナ・エウレカ・アーネスト**の物語を描く長編RPGです。

## ストーリー

西暦3509年（E509）——アルファ・ヴェノムの襲撃で故郷ノスタルジア・コロニーを失った少女ミナ。
12年後、書庫惑星ビブロを旅立った彼女は、AURALIS二代目の一員として、
45年に及ぶ「夜」の黒幕・**アルファ・ヴェノム・シグマロード**に挑む。

- **プロローグ**：ノスタルジアの夜（E509）
- **第一章**：書庫都市ビブロ（E521）
- **第二章**：企業国家ギガポリス（E522）
- **第三章**：三日月の大地（E523）
- **第四章**：惑星エロスの女王（E524）
- **第五章**：タルタロスの真実（E524）
- **終章**：光と音を永遠に（E525）
- **クリア後**：裏ボス「ジェン」（Lv938+）が地下都市の最奥に出現

## 特徴

- 🎮 **FF風コマンドバトル**：たたかう/スキル/どうぐ/ぼうぎょ/にげる、弱点属性、会心、ボス多段階フェーズ
- 👥 **パーティ5人**：ミナ（プロデューサー）/ レイラ（ピンク・ヴォルテージ）/ ケイト（ガンナー）/ リリィ（ホワイトメイジ）/ ニニー（サモナー）
- 🗺️ **12以上のフィールド/ダンジョン**：ランダムエンカウント、宝箱、ショップ、宿屋、セーブ端末
- ⚔️ **7つのボス戦 + 裏ボス**：専用BGM・多段階フェーズ・必殺技
- 🎵 **WebAudio生成チップチューン**：14曲のBGMと20種以上のSE（外部音源ゼロ）
- 💾 **オートセーブ + 任意セーブ**（localStorage）
- 📱 **PWA完全対応**：オフライン playable / ホーム画面追加 / アプリアイコン / スクリーンショット / ショートカット

## PWA

- `manifest.webmanifest` — アイコン（any + maskable）、スクリーンショット、ショートカット、landscape
- `sw.js` — 全アセット プレキャッシュ、stale-while-revalidate、旧キャッシュ自動削除
- 初回アクセス後に **完全オフライン** で動作。インストールボタン表示対応（beforeinstallprompt）

## ディレクトリ構成

```
gamemina/
├── index.html            # ゲーム本体（単一ページ）
├── 404.html              # 次元の裂け目 404
├── manifest.webmanifest  # PWA マニフェスト
├── sw.js                 # Service Worker（オフライン）
├── favicon.svg
├── css/game.css
├── icons/                # PWA アイコン / スクリーンショット
└── js/
    ├── data_core.js      # キャラ/スキル/アイテム/装備/ショップ
    ├── data_enemies.js   # エネミー/ボス/エンカウント
    ├── data_maps.js      # マップ/イベント
    ├── data_story_a.js   # シナリオ（プロローグ〜三章）
    ├── data_story_b.js   # シナリオ（四章〜終章）
    ├── audio.js          # WebAudio BGM/SE エンジン
    ├── engine.js         # コア（状態/入力/セーブ/育成）
    ├── field.js          # フィールド描画/移動/イベント
    ├── menu.js           # メニュー/ショップ/宿屋
    ├── story.js          # カットシーン/タイトル/ゲームオーバー
    ├── battle.js         # バトルシステム
    └── main.js           # ループ/PWA 起動
```
